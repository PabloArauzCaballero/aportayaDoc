# `tokens/` — no es de este carril

El sistema de diseño (tokens, átomos y moléculas compartidos) es de la fase **F1**,
carril `F1 · Sistema de diseño`, que posee `packages/ui/**` y `apps/*/src/tokens/**`.

Lo que hay acá es **andamiaje**: los valores mínimos para que la pantalla de la fase
F0 se vea, no un sistema de diseño. **Al cerrar F1 este archivo se borra** y los
componentes importan de `@aportaya/ui`.
